## CountV1-5.lsp -> Blocks counter (+table generation)
This program enables the user to record the quantities of a selection or all standard or dynamic blocks in the working drawing. The results of the block count may be displayed at the AutoCAD/BricsCAD command-line, written to a Text or CSV file, or displayed in an AutoCAD Table, where available. From [https://www.lee-mac.com/blockcounter.html](https://www.lee-mac.com/blockcounter.html)
